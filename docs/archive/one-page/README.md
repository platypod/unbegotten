# Archived one-page designs

Superseded editions of [the one-page design](../../game/one-page.en.md), kept
verbatim rather than deleted, because Librande's own rule for this format is
that a wall poster is worthless if nobody can tell which version they are
looking at — which only works if the old versions still exist to be told
apart from.

Nothing in here is maintained. If a claim in an archived edition contradicts
the current one, the current one wins.

| Edition | Superseded | Why |
|---|---|---|
| `one-page.2026-09-06.en.svg` · `.fr.svg` | 2026-09-07 | The first one-pager. A strong statement of the world and a weak one of the game: no figures despite citing Librande's *visual first* rule, no verbs, no antagonist, no failure state, and a build-state chip too coarse to separate "the geometry runs" from "the mechanic exists". The [v2 wrapper](../../game/one-page.en.md#what-changed-in-v2) lists what changed and why. |
